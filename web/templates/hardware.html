RULEBOOK

4 Critical Wiring Rules for Beginners

Before plugging in any wires, read these 4 golden rules to avoid damaging components during assembly or live demonstration:

1. Common Ground (GND) is Mandatory

ALL components (ESP32, sensors, relays, LoRa modules, and power supplies) connected together MUST share a common GND wire. Without a continuous reference ground, analog ADC voltages fluctuate wildly and SPI/I2C communication will fail completely.

2. ESP32 3.3V Logic Warning

ESP32 GPIO pins operate strictly at 3.3V logic level. Connecting 5V directly to an ESP32 input pin will permanently destroy the microcontroller. For 5V sensors like MQ-2 or MQ-135, power the sensor heater with 5V, but ensure analog outputs stay below 3.3V (or use a voltage divider).

3. ADC1 vs ADC2 Pin Rule (Wireless Rule)

Always use ADC1 pins (GPIO 32, 34, 35, 36, 39) for analog sensors when LoRa or WiFi is enabled. ADC2 pins (GPIO 0, 2, 4, 12-15, 25-27) cannot be used while wireless radio modules are active!

4. SIM800L Power Peak Requirement

The SIM800L GSM module requires 3.7V – 4.2V with at least 2 Amps burst current during cellular transmission. Do NOT power SIM800L directly from Jetson 3.3V/5V pins! Use a dedicated 18650 Li-ion cell or high-current LM2596 buck converter with shared GND.

Power Wiring Instructions

  1. Solar Panel (+ / -) → Connected to IN+ and IN- on TP4056 board.
  2. 18650 Li-ion Battery (+ / -) → Connected to B+ and B- on TP4056.
  3. TP4056 OUT+ → Connected to ESP32 VIN pin (or 5V sensor power rail).
  4. TP4056 OUT- → Connected to ESP32 GND pin.

Battery Divider Voltage Monitor Circuit

Allows the ESP32 to monitor real battery capacity safely via 12-bit ADC without exceeding 3.3V:

Battery B+ → 10kΩ → ESP32 GPIO 36 (ADC1_CH0) → 10kΩ → GND

V_measured = V_battery / 2 ≤ 2.1V (well within the safe 3.3V ADC range).
